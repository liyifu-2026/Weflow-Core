# 12 · 配置与环境变量

> 出处：`core/infrastructure/config/config.ts`（zod schema 单点）、`core/.env.example`
> （与 schema 一一对应）、`runtimes/channel-host-wechat`（channel-host env）、
> `weflowctl`（REQUIRED_ENV_KEYS）、设置中心实现。

## 1. Core 环境变量（`core/.env`）

通用规则：敏感键（`*_API_KEY` / `DATABASE_URL` / `REDIS_URL` / `CHANNEL_HOST_TOKEN`）支持
`*_FILE` secret 文件注入（`_FILE` 优先且不做存在性检查）。`.env` 修改后需重启进程生效
（`weflowctl service restart`）。

### 进程与端口

| 变量 | 默认 | 说明 |
|------|------|------|
| `NODE_ENV` | development | development / test / production |
| `LOG_LEVEL` | info | pino 日志级别 |
| `HEALTH_HOST` | 127.0.0.1 | 健康检查绑定地址 |
| `CORE_PORT` | 3100 | api 端口 |
| `AGENT_WORKER_HEALTH_PORT` | 3101 | agent-worker 探针 |
| `INGESTION_WORKER_HEALTH_PORT` | 3102 | ingestion-worker 探针 |
| `AGENT_WORKER_CONCURRENCY` | 3 | Agent 全局并发（1–20） |
| `MEMORY_CAPTURE_CONCURRENCY` | 1 | 记忆捕获并发（≤5） |
| `MEDIA_PROCESSING_CONCURRENCY` | 1 | 媒体处理并发（防多模态过载） |

### 存储（必填）

| 变量 | 说明 |
|------|------|
| `DATABASE_URL` | **必填**。PostgreSQL 连接串 |
| `REDIS_URL` | **必填**。Redis 连接串 |
| `FILE_STORAGE_ROOT` | 默认 `.data/files`；X230 = `C:\We\weflow\core\.data\files` |

### Channel Host（不配置 = 纯平台模式）

| 变量 | 说明 |
|------|------|
| `CHANNEL_HOST_BASE_URL` | 与 TOKEN **成对必填**（单独一个启动报错）；如 `http://127.0.0.1:43123` |
| `CHANNEL_HOST_TOKEN` | Bearer token（两端一致） |
| `CHANNEL_HOST_POLL_INTERVAL_MS` | 默认 500（≥250） |

### 模型族（业务运行必配 MODEL_API_KEY；纯平台可缺）

| 变量 | 默认 | 说明 |
|------|------|------|
| `MODEL_BASE_URL` | `https://api.deepseek.com` | 主决策模型 OpenAI 兼容端点 |
| `MODEL_API_KEY` | — | 配了才有 model 能力 |
| `MODEL_NAME` | `deepseek-v4-flash` | 槽位未绑定时的启动兜底名（运行期唯一事实源 = DB 模型注册表） |
| `MODEL_TIMEOUT_MS` | 60000 | 补全超时 |
| `MODEL_MAX_TOKENS` | 16384 | 单次补全预算（含思维链） |

### WeKnora 知识库与桥接

| 变量 | 默认 | 说明 |
|------|------|------|
| `WEKNORA_BASE_URL` | `http://localhost/api/v1` | 检索 API 基址 |
| `WEKNORA_API_KEY` | — | 配了才有 weknora 能力 |
| `WEKNORA_TIMEOUT_MS` | 15000 | 超时（最小 1000） |
| `WEKNORA_KNOWLEDGE_BASE_IDS` | — | 逗号分隔白名单；缺省自动发现 |
| `WEKNORA_ORIGIN` | — | WeKnora 站点 origin（桥接 302；缺省从 BASE_URL 剥 `/api/v1`） |
| `KNORA_ACCOUNT_ENC_KEY` | — | 代管凭证加密密钥（≥8 字符；缺失桥接路由 503） |
| `KNORA_TENANT_ID` | 10000 | WeKnora 租户 |
| `KNORA_ACCOUNT_EMAIL_DOMAIN` | weflow.com | 合成邮箱域 |

### 安全 / HTTP / 行为

| 变量 | 默认 | 说明 |
|------|------|------|
| `SESSION_COOKIE_SECURE` | **默认 true（所有环境，config.ts 无条件 `.default("true")`）** | 局域网 HTTP 部署必须显式 `false`（否则登录即掉）；HTTPS 部署保持默认 |
| `SESSION_COOKIE_DOMAIN` | — | Cookie domain（schema 外直读） |
| `CORS_ORIGINS` | — | 逗号分隔 origin；不配置不开放跨域 |
| `WEB_DIST_DIR` | — | support-web dist 目录；未配置 api 不注册静态路由（开发互不影响） |
| `AVATAR_ALLOWED_HOSTS` | — | 头像代理域名后缀白名单；**不配置 = 一律拒绝** |
| `AVATAR_PROXY_TIMEOUT_MS` / `AVATAR_CACHE_TTL_MS` | 5000 / 3600000 | 头像代理 |
| `BEHAVIOR_SETTINGS_REF` | — | `<solutionId>/<extensionId>`（ADR-0015）；客服部署 = `weflow.customer-support/support-pipeline`；未配置 = 纯平台模式 |

### schema 外直读

| 变量 | 说明 |
|------|------|
| `WEFLOW_PLUGIN_DIR` | 业务插件目录直读根（默认 `../solutions/customer-support`）；未设 = 不加载插件 |
| `VOICE_FFMPEG_PATH` / `FFMPEG_PATH` | 语音转码 ffmpeg（工作区根 `tools/ffmpeg/ffmpeg.exe`；改路径勿改代码） |
| `VOICE_PYTHON_PATH` / `PYTHON_PATH` | channel-host venv python（pysilk；**绝不指向系统 Python**） |
| `STRATEGY_PLUGIN_PATH` / `SKILL_PLUGIN_PATH` | 旧式单插件路径（仅测试/兼容） |

**非 env 的代码常量**（易被误认为配置，改动需发版）：知识代理上传上限
`MAX_KNOWLEDGE_UPLOAD_BYTES = 25MB`（`knowledge-provider/application/boundary.ts`）、
fetch_url 上限（256KB 响应体 / 8000 字正文，`execute-tool-plan.ts`）、决策协议钳制
（reply ≤8 段 × 500 字、wait 30s–900s）、合并窗默认 12s/30s（**代码常量，无 env/设置入口**；
turn-admission 预留了参数接缝但主链路固定取默认值）、记忆安静窗口
`MEMORY_QUIET_WINDOW_MS = 90s`（同为代码常量，不可配）。

weflowctl `REQUIRED_ENV_KEYS`（`dev doctor` 检查）：`DATABASE_URL`、`REDIS_URL`、`CORE_PORT`、
`CHANNEL_HOST_BASE_URL`、`CHANNEL_HOST_TOKEN`、`MODEL_BASE_URL`、`MODEL_NAME`、`MODEL_API_KEY`、
`WEKNORA_BASE_URL`、`WEKNORA_API_KEY`（允许 `*_FILE` 形式）。

## 2. Channel Host 环境变量

见 07 章 §7 全表（`CHANNEL_HOST_TOKEN` 必填、事件库/媒体暂存路径、端口 43123、发送超时 180s、

## 3. 设置中心（界面热配置，替代改配置文件）

| 配置面 | 存储 | 热生效 | 内容 |
|--------|------|--------|------|
| 全局开关 ×7 | `operations.runtime_settings` | 消费方热读 | Kill Switch/自动发送/合并窗口/插话闸门/知识检索/长期记忆/图像理解（+ 回滚 + 审计） |
| 模型注册表 + 槽位 | `operations.model_registry` | 15s 轮询 | 五槽位 text/vision/asr/triage/fast + 故障转移链 + 连通性测试 |
| 行为参数 | `extension_settings`（`behavior` 键） | agent-worker 30s TTL | 会话 TTL/轮数/wait 缺省等待（defaultWaitMs 300s，非上限）/nudge/提醒/步预算 |
| 群聊策略 | `extension_settings`（`groupChat` 键） | 30s | 模式/关键词/冷却/概率/额外指令/按群 override |
| 知识库连接器 | `extension_settings`（`knowledgeConnector` 键） | 30s | 端点/认证/KB 范围/字段映射；缺省逐项回落 env |
| AI 员工 | `customer_support.ai_employee_*` | 版本发布即生效（新 Turn） | 人设 prompt 版本流（draft→published→retired） |

三层配置的优先级约定（ADR-0011/0015）：**引擎缺省一律中立/空 → 部署种子只补缺不覆盖 →
设置中心为唯一日常界面入口 → env 为兜底**。

## 4. 密钥卫生（红线）

- 明文敏感物（永不入库/入文档）：`core/.env`、`x230-deploy/core-env*.txt`（含真实密钥快照）、
  `scripts/.server-credentials.txt`、frpc token、`KNORA_ACCOUNT_ENC_KEY`。
- `.gitignore` 已排除 `.env*`（保留 `.env.example` / `.env.production.example`）、`.npmrc`、
  frpc 二进制/配置/日志。
- 文档中只许出现**键名**，不许出现值；`model_registry.api_key` 只写不读（读取仅返回 hasApiKey）；
  channel-host 密钥端点绝不回显密钥。
- 工作树当前不宜入库文件（v1.2.0 提交时清理）：`apps/desktop/python-3.12.10-amd64.exe`（26MB
  安装器，正确去处是 U 盘 installers）、`core/.tmp-vision-test.jpg`（调试残留）。
