## 5. e2e gate（`solutions/scripts/e2e-gate.mjs`）

- 前提：平台在跑（api + agent-worker + `MODEL_API_KEY`）。
- 动作：绕过 Channel Host，pg 直写种一条会话+入站消息+queued Turn → BullMQ 入队 → 等 worker
  处理 → 打印回复与事件 → 清理测试数据。
- 用法：默认设备故障消息期望 reply；`--message "我要退款" --expect handoff`；
  `--expect any --keep` 保留数据排查；`--timeout 90`。
- **退出码语义**：0=过关（completed 且符合期望）；2=完成但结果不符；1=失败/超时/异常。

## 6. platform:verify 与 CI

- `pnpm platform:verify`（`weflow/scripts/platform-verify.mjs`）按序执行 **9 个 pnpm 步 +
  1 项协议对齐检查（共 10 个执行块）**，任一失败立即退出非零：contracts build、contracts
  test、plugin-sdk build、plugin-sdk test、ui build、ui test、**core `check`**
  （check:migrations + format:check + lint + typecheck + test）、weflowctl typecheck、
  weflowctl build，最后 Channel 协议跨语言对齐（`sync-channel-protocol.ts --check`，
  产出文件头 DO NOT EDIT）。
- `platform:verify:ci`：强制 `TEST_DATABASE_URL`（否则本地模式 WARN 跳过集成测试）。
- **GitHub Actions**（`.github/workflows/phase7-verify.yml`）：
  - job `verify`（ubuntu）：services postgres:16（weflow_test）+ redis:7 → Node 24 + pnpm
    10.34.5 → install:all → `core check:migrations`（迁移与 journal 1:1）→ migrate →
    `platform:verify:ci`。
  - job `business`（ubuntu）：solutions `install:all` + `build`（support-web + 插件构建门禁）。

## 8. 测试纪律（来自 core/AGENTS.md 与错题本）

- 模型输出按 Agent 决策 schema 校验；未知动作/字段**拒绝而非猜测**。
- 竞态必须测试：吸收式回合矩阵逐格钉住；工具租约恢复；发送结果 unknown 对账。
- 改动提交前：`pnpm typecheck` + 定向 `pnpm test` + lint + format（core）；weflowctl 改动
  `pnpm build && pnpm test`；业务改动过 e2e gate。
- 错题本（`weflow/docs/error-log.md`）条目全部转化为预防机制（create-user 哈希验证步骤、
  reset-password CLI、迁移后登录 smoke、admin 契约差集检查）。
