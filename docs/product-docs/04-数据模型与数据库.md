# 04 · 数据模型与数据库

> 出处：`core/infrastructure/postgres/schema.ts`（1617 行，Drizzle 单文件 schema）、
> `core/migrations/`（77 个编号 SQL 迁移 + `meta/_journal.json` 77 条）。

## 1. 迁移体系

- 迁移目录 `core/migrations/`，编号 0000–0080（缺 0046/0047/0058/0075 四个编号），共 **77 个文件**，
  journal 一一对应（`check:migrations` 校验 1:1，CI 强制）。
- **禁止改写已应用迁移**；每次 schema 变更加编号 SQL + journal 条目。
- 执行：开发 `pnpm migrate`；生产 `pnpm migrate:prod`（幂等，可重复）。
  `weflowctl dev up` 会在业务表缺失时自动跑迁移。
- 最新 5 个迁移：`0076_chat_type`（会话类型落库）、`0077_emotion_text_only`（表情包文本化）、
  `0078_blacklist_default`（黑名单制默认值）、`0079_blacklist_backfill`（存量回填）、
  `0080_send_state_vocabulary`（发送状态 8 态词表 CHECK 约束）。
- 0061 迁移创建 `customer_support` schema（业务 AI 员工表）——业务子树迁移搭乘引擎迁移列车（ADR-0014）。
- 历史保留：0048–0053 可见 R3 拆除 solution store 的 journal；0056 删除 `case_states`（ADR-0004）。

| `turn_admission_states` | last_message_id、message_count、status(scheduled…)、scheduled_at、attempt | 合并窗口登记（连发 upsert 重置收窗，到期 CAS 认领） |

### identity
| 表 | 关键字段 | 用途 |
|----|----------|------|
| `users` | username（唯一）、password_hash（argon2）、role(operator/admin)、must_change_password（默认 true）、avatar_file_id/preset、display_name、tags（=队列 key） | 登录用户 |

### notification
`devices`（push_token 唯一、platform、show_preview、notify_kinds）、`outbox`

### audit
`events`（actor_user_id、event_type、subject_type/id、source_ip、metadata）。

`GET /api/v1/admin/audit/options` 取 distinct 值（登录/用户管理/Handoff 操作/设置变更/
知识代理变更等均落审计）。

## 4. 数据保留与隐私要点

- 媒体字节只存磁盘（`FILE_STORAGE_ROOT`，X230：`C:\We\weflow\core\.data\files`，频道媒体落 `\media\<key>`），
  数据库仅元数据，**绝无 base64**。
- 会话 token 只存 sha256 摘要；WeKnora 代管凭证 AES-256-GCM 加密（密钥在 env）。
- 手机端图片缓存只进内存不落盘（0.9.0 修复）；离线 transcript 缓存 ≤20 会话/100KB/24h 且图片文件只存占位。
- 历史消息不可变（占位替换只在摄取时做一次）；`converge:legacy-media` 可把旧媒体记录收敛为明确不可用状态。
- 迁移前快照规程（pg_dump）见 13 章 §热更新。
